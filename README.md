# Risk Analysis of Stock Prices: Connections with Chaos and Fractals

## About
This repo explores the use of chaos and fractals to analyze risk in stock prices.

## Setup

1. Clone the repository:
```bash
git clone https://github.com/cinnamon1952/StockParticle
cd StockParticle
```
2. Create Virtual Environment
```bash  
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
